Jerron Skiba To-Do List

This is a command line To-Do list program written in Java. Every task has a name and priority. All of these task items are stored in a custom MaxHeap built with some array hackery in Java. This results in higher-priority tasks always being at the top, and the ability to peek the current urgent tax.

With this program you can:

- Create a new task with a name and priority
- Peek the highest priority task WITHOUT REMOVING IT
- Remove (Pop) the highest priority task to complete it

To run, just compile all the Java code in the 'src' folder and run 'ToDoApp'
